# 合成配方与检查契约

当候选种子已经选定、准备进入设计或实现时读取。目标是把“看起来像”改成可追溯的约束组合，避免参照在执行中退化成模糊印象。

## 1. 冻结输入

先固定这些事实，不替用户补造：

- `goal`：产物要完成的一个主要任务；
- `audience`：第一阅读者或操作者；
- `carrier`：网页、App 界面、海报、封面、信息图、社媒画幅或学术插图；
- `size_or_ratio`：画幅、视口或关键断点；
- `exact_content`：必须逐字保留的标题、标签、数据和署名；
- `assets`：用户给定的人物、对象、图像、图表或品牌资产；
- `must_keep` / `must_avoid`：明确约束与禁区。

复杂主题只选一个主要视觉命题。不要试图把每个论点都变成一个装饰元素。

## 2. 给参照分配角色

每次选 1–3 个种子。先逐个 `show`，再为每个种子填写：

- `assigned_dimensions`：本次只向它借哪些维度；
- `wow`：一个最值得保留的决定，而不是“整体感觉”；
- `borrowed_constraints`：可执行的色值、比例、字号关系、网格、动效参数、材质或交互逻辑；
- `deliberate_departures`：为当前内容主动改变什么。

一个种子可以作为全局锚点；其他种子只补它没有覆盖的维度。两个参照若对同一维度给出冲突答案，必须选一个，不做折中平均。不要把三个完整风格叠成拼贴。

## 3. 锁定合成节奏

每个独立关键画面、页面首屏或主要信息段只设一个 `focal_event`：例如异常尺度的大字、极端裁切、一个高密度数据簇、一次明确的色彩碰撞或一个决定性交互。其他高能元素只能延伸这个事件，不能另起中心。

同时指定一个 `release_zone`。它不是机械的空白比例，而是明显更低的信息压力：

- 海报或封面可以是露出的纸面、低对比图像区或稀疏辅助字；
- 网站可以是大留白、安静背景、单一对齐或无动效区；
- 仪表盘可以是稳定网格、低饱和区域、减少装饰的阅读带，而不必删掉必要数据；
- 学术插图可以是无标注缓冲带或层级更弱的上下文结构。

缩略图或第一眼检查时，焦点应立即可辨，释放区应明显更安静。`relaxed` 不等于所有元素都小、淡、均匀；它应是能量集中后有空间释放。

## 4. 填满 recipe

运行：

```bash
python3 scripts/muse_local.py recipe <id> [<id> ...] --brief "用户原始需求"
```

命令输出固定 JSON 草案。进入实现前，所有适用的 `null`、空数组和空对象都要被实际决定替换；不适用项写明原因，不能静默略过。

- `synthesis.layout`：结构、密度与响应式行为；
- `synthesis.typography`：展示声部、工具声部及实际语言字符覆盖；
- `synthesis.color`：来自参照的原始 token、角色分配及必要的同体系派生；
- `synthesis.imagery/motion/craft`：图像角色、动效因果与材质工艺；
- `implementation_requirements`：不能降级的技术、状态、交互和可访问性要求；
- `quality_gate`：逐项填 `pass` / `fail` / `not_applicable` 与证据。

颜色先分配角色再实现。背景、正文、强调、状态色都要能追溯到参照；参照没有的语义色只能沿同一色温、饱和度和明度阶梯推导，并在 `derived_tokens` 记录来源。字体必须覆盖最终文本的语言和字符，不能让中文或特殊符号悄悄掉回无关字体。

动效、材质和“不完美”只在内容与参照支持时使用。随机纹理、抖动或错位不得掩盖构图问题；需要重试时，已确认的构图、焦点、色板和工艺强度保持稳定。

## 5. 原创性防火墙

参照提供的是视觉语法，不是待描摹的模板。不得复刻独特的对象排列、标题断行、标识、文案、边框系统、插画或签名。

相对任何一个参照，至少明确改变四项结构变量，并写入 `structural_changes`：

- 内容主体与图像角色；
- 裁切或对象数量；
- 网格与信息拓扑；
- 标题位置、断行或尺度关系；
- 字体配对；
- 画幅与响应式行为；
- 组件组织；
- 动效触发与节奏；
- 材质或工艺的应用位置。

用户要求“原样照着做”时，保留其目标与内容，转译系统级品质；不要复制可识别构图。

## 6. 最终检查

实现后同时看真实尺寸和缩略视图；界面类产物再覆盖关键状态、内容极值、响应式、键盘焦点和可访问性。

逐项确认：

1. 每个参照都已深读且角色不冲突；
2. 只有一个主焦点，且有一个更安静的释放区；
3. 色彩、字体、布局、动效与工艺均有来源和明确角色；
4. 用户的文字、数据、人物与对象保持正确；
5. 参照中的高价值技术没有为省工而降级；
6. 至少四项结构变量已主动改变，没有复制专有表达；
7. 最终产物而非 recipe 本身通过了目标尺寸检查。

`python3 scripts/muse_local.py validate` 只证明本地种子库结构一致，不能替代对最终视觉产物的人工检查。
