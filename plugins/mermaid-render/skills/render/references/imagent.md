# Imagent 方式

`imagent` 直接用当前可用的图片生成或图片编辑能力创作最终图。不要先生成 HTML、截取 HTML，或把 HTML 构图当作必须复刻的中间层。

## 创作空间

- 把 Mermaid 的语义整理成清楚的画面关系，再结合所选风格写图像生成指令；不要先翻译成固定卡片系统。
- 可以主动为节点设计与含义相关的图标、物件、人物动作、微场景或空间隐喻。插图用于帮助辨认与记忆，不得凭空增加流程步骤。
- 节点不必都是矩形，关系也不必都是工程图折线；只要方向、连接和阅读顺序仍然准确清楚。
- 允许根据首图继续生成或局部编辑，直到作品与结构都成立。不要设置“一次编辑”“固定回退”等机械限制。
- 用户给了参考图时，把它用于视觉语气，不复制其中的业务文字、品牌元素或拓扑。

## 提示与复核

生成指令应同时包含：画面目的、所选风格、必须出现的准确文字、关系与方向、希望主动配图的节点、禁止新增或丢失的内容。给模型足够的整体意图，不要用像素坐标和冗长 CSS 语言束缚它。

图片生成后必须实际打开原图，逐字核对可见文字，逐边核对连接和箭头。若生成模型始终无法保真，明确说明限制，并让用户选择继续 Imagent、简化内容或改用 HTML；不要静默换方式。
