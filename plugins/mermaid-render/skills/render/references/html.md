# HTML 方式

`html` 是一件可编辑的网页视觉作品，不是固定模板，也不等同于给 Mermaid 默认 SVG 换色。

## 创作空间

- 自由使用 HTML、CSS、SVG、Canvas 或少量 JavaScript；可把 Mermaid 引擎当作解析或布局助手，但不必保留它的默认节点外观。
- 先规划节点网格：为每个节点、标题、图例和注释分配不重叠的区域，并在区域之间预留连接线槽；再决定画布比例、节点形态和排版。流程、循环、分支、泳道和架构图不必共用一种布局。
- 连接线适合用 SVG 单独绘制，以便控制路径、箭头、层级和避让；节点本身可以是文字、卡片、图形或插图。
- 除连接线外，不允许任何元素相互覆盖。连接线可以交叉或从视觉层级后方经过，但不得穿过 label、箭头终点含糊，或让读者误判连接所属。
- Swiss Style 与 JAPANESE MA 也必须保留可追踪的节点网格；留白、跨栏与不对称只能改变节奏，不能代替结构。
- 页面应自包含、在常见桌面浏览器直接打开，并在目标视口内保持清晰。只在确有必要时引入外部依赖。
- 保留可访问的文字层。不要把所有文字烘焙进背景图，也不要为了截图牺牲可编辑性。

## 判断完成

先在浏览器中看完整构图，再检查窄窗口或目标导出尺寸。逐项确认：所有非连线元素互不覆盖；节点落在可理解的行列中；文字无截断；连接线尽量走线槽，不穿 label；箭头方向和终点明确；没有无意滚动条。修正真实问题即可，不追求统一模板的像素一致。
