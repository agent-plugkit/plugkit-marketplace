# 深色是变体，网页按变体对跟随系统

从项目里提取出的成对浅色 / 深色值，落成 `light` 和 `dark` 两个变体。颜色写进颜色 Seed 的 `variants`；阴影、高光这类颜色以外的深色值，写进各自 Seed 的 `variants`，用同一个变体名。海报、演示文稿这类单一外观的作品每次解析一个变体。web 场景不指定变体时，同时有这两个变体的 Template 解析为跟随系统：`:root` 是浅色，`@media (prefers-color-scheme: dark)` 块只写深色下变了的值，检查脚本在两种配色下都截图检查。

我们没有给 Seed 另加一个 `dark` 字段，也没有让深色和其他变体（如强调色变体）两两组合。原因是浅色和深色本来就是两套完整的取值，对比度检查也已经按变体逐个做；用变体表达，schema 只多一条约定（`light` 和 `dark` 这两个名字成对），没有新的组合规则要维护。代价是深色不能与另一组变体叠加：一个风格既要多种强调色、又要每种都有深色时，只能把每种组合写成单独的变体，那时再重新考虑。

最初的决定是只做变体、不输出跟随系统的两套值；有了要跟随系统深浅色的网页之后，改成现在的做法。
