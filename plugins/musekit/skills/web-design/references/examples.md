# 界面制作示例

五份示例用同一条流程做同一类任务：为一个虚构的活动或刊物做官网首页（单个 HTML，靠照片的两份另带照片文件），没有现有项目和服务端，主任务是填一张表单。前三份只靠文字和版面，后两份的风格离不开照片：先生成照片、核对照片，再排版。风格不同，页面的切分方式、主操作的位置和状态的形态都不同。读它们是为了学**判断过程**：怎样从 Brief 和 style.md 推出每个视口的区域与栏位，评审在浏览器里查出了什么、怎样修正。不照搬构图、文案和代码结构；换一个风格或换一项任务，结论都要重新推导。首屏的构图多半由风格的 web 适配直接规定，和示例相同是正常的；要学的是首屏以下怎样切分，以及评审怎样发现和修正问题。

| | [新粗野主义：《造物集市》](examples/neo-brutalism-maker-fair.md) | [编辑衬线：《长河》季刊](examples/editorial-serif-long-river.md) | [日式留白：「窑开」开窑日](examples/japanese-ma-kiln-opening.md) |
| --- | --- | --- | --- |
| 主任务 | 报名摆摊（类别格可以预选类别） | 订阅季刊 | 报名两天四场中的一场 |
| 页面原型 | 介绍与转化 + 完成任务 | 介绍与转化 + 完成任务 | 介绍与转化 + 完成任务 |
| 页面怎样切分 | 三面拼板墙，每面墙的切分方式不同，每面都有顶满的标题和压缝贴片 | 一张扉页式首屏，下面是用通栏细线隔开的居中章节 | 偏心竖排标题的首屏，下面两章用大段停顿隔开，竖排章节名左右交替 |
| 手机上怎样重排 | 板单列堆叠，仍共用横线 | 中轴不变，旁注移到正文之前，版权行按事实断行 | 竖排标题缩到首屏三分之一，副题改横排；章节名仍竖排 |
| 状态的形态 | 出错时边框加粗并贴一张原因标签；完成后表单板换成主色 | 出错时底线加粗加一行强调色说明；聚焦用描边框；完成后居中的确认文字替换表单 | 选中用墨框加朱色小方点；出错底线加粗加墨色说明；完成后安静的确认文字替换表单 |
| 评审改得最多的 | 首屏以下的墙不满足文法；贴片在窄屏压住可点击的格子 | 示例标注缺失、完成态措辞失实、聚焦与出错分不开 | 首屏标题不够大、没有唯一焦点；手机首屏放不下导语 |

| | [隔纱：栖苇植物园春季开放日](examples/veiled-frame-spring-garden.md) | [暗场：「冬夜篝火朗读会」](examples/dark-stage-fireside-reading.md) |
| --- | --- | --- |
| 主任务 | 预约三天六场中的一场 | 报名来听或来读（选来读时多填篇目） |
| 页面原型 | 介绍与转化 + 完成任务 | 介绍与转化 + 完成任务 |
| 照片怎样用 | 每个画框一张照片，纱面盖住安静处并跨过一道明暗边界；照片按纱面的位置生成 | 首屏三层：照片、字标、从同一张照片抠出的前景；前景是暗剪影，压住字标下缘 |
| 页面怎样切分 | 三个满幅画框交替用竖条、横带和角块纱面，长内容和表单排在纸色平底段落 | 一个满幅暗场首屏，下面退成平底段落，中间夹一个不放字标的章节画框 |
| 手机上怎样重排 | 换竖构图照片，纱面都改横带；巨字只用一个字，完整的词写进标题行 | 换竖构图照片和前景，字标位置跟着裁切重算；上边一行收成名称和「菜单」 |
| 状态的形态 | 选中墨底纸色字加「✓」；出错加「✕」和一行墨色说明；完成后原位回显 | 选中强调色描边加「✓」；出错加「✕」和说明；完成后原位复述 |
| 评审改得最多的 | 宽矮屏上纱面贴到画框上边、上下组挤在一起；场次的可访问名称缺日期；两个墨底按钮争焦点 | 空提交后看不到焦点落在哪；滚动后 Tab 重复经过首屏导航；生成照片里多出一截手指 |

前三份示例是风格验收或盲测时做的，后两份是风格验收之后专门为风格库做的；评审都走了完整档（空白上下文评审者，多轮复查），Brief 和栏位表也为了讲清判断过程写得很全。正式制作默认走[默认档](../../../references/critique.md#默认档)；Brief 写在对话里，栏位决定在交付说明里用几句话交代就够了。

五件作品都没有后端：完成态如实写「信息没有发送」，不伪造提交成功；用户没给的事实（价格、网址、联系方式）写「待公布」。
