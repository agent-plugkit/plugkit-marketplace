三条看花路线

柳岸、温室、樱坡

每条走完约一小时示例

  1. 柳岸线

    沿湖岸走，看新出的柳叶和去年留下的芦苇。湖边风大，带一件外套。

    约一小时 · 平路

  2. 温室线

    穿过热带温室的喷雾区，芭蕉和龟背竹都在这里。喷雾时段地面湿滑。

    约一小时 · 室内

  3. 樱坡线

    从草坪走上樱花坡，花期以开放日当天为准。

    约一小时 · 有缓坡
