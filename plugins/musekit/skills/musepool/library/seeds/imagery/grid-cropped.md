# 网格裁切图像

## 要点

- 图像裁成直角矩形，宽度占整数个栏，边缘对齐栏线或直接出血。
- 裁切服务主体：保留主体的关键特征，用大胆的局部裁切制造张力，而不是整图缩小放进框里。
- 可以转为灰度，让唯一的强调色不被照片色彩稀释；色彩本身是内容时保留原色。

## 适用与边界

没有真实图像时不要用灰块或假照片填满模块；让文字和留白承担版面。
