# 单光源暗场与可抠的前景

## 要点

- 照片是暗场：大部分是暗部，只有一处光源（火、灯、烛、月、窗、屏幕），光落在中景。光的颜色决定颜色 Seed 的变体。
- 离镜头近的地方有一个轮廓清楚的前景：礁石、山脊、肩背、器物、桌沿。它和后面的光之间有明暗反差，轮廓才抠得干净。烟、枝叶、大片散发这类发虚的轮廓不用来压字。
- 横贯画框的前景（山脊、礁石、书堆），轮廓在字标下面大致水平：字标下方那一段的高低差不超过字标笔画高的约十分之一，每个字才能被压到相近的深度。斜坡或一高一低的轮廓留给单个物体的写法，或者换一张。
- 前景是暗的剪影：光只勾出它的轮廓（逆光、轮廓光），靠近画框边的部分沉在暗里。贴边小字就落在这片暗里；前景要是一直亮到画框边（湿石反光、被灯照亮的琴身），暗角压不住，小字底下就会过亮。
- 生成照片时按画框比例生成，提示词写明光源的位置、前景占画面下部或侧边多少、轮廓清楚，并写明前景是暗剪影、只有上缘被光勾亮、靠画框边的部分几乎全黑；画框上下边写成「深暗的天空、墙或地面」，不写成「什么都没有的空白」。不生成带有真实人物身份、品牌或地标的照片。
- 每张照片配一张前景遮罩：用生图工具以原图为输入生成黑白遮罩（同样的构图和尺寸，前景纯白，其余纯黑，边缘贴着前景轮廓）。再用 `cutout.mjs` 合成带透明通道的前景 PNG，并用 `--check` 导出的轮廓图核对红线是否贴着前景；不贴就重生成遮罩，不手工凑。
- 前景用 `<img>` 叠在字标上，不用 CSS `mask`：`file://` 打开页面时，`mask` 引用的本地图片按跨域资源处理，前景整块不显示。

## 适用与边界

没有照片时不用这个风格：暗场和前景是它的一半，换成纯色或渐变就只剩一行大字。用户提供的照片照原样使用，遮罩也按它生成；生成的遮罩对不上而又不能重生成时，这个画框不放字标。
