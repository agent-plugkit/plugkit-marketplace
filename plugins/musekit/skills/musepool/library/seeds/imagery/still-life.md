# 静物与局部

## 要点

- 图像只拍一个主体或一个局部：一本书的书脊、一只杯子、一块水面。主体周围留出大片自然的空。
- 自然光，低饱和，阴影柔和；色调与纸色相近，让图像融进版面。
- 图像不加边框，不与文字重叠；它本身就是一块留白中的焦点。

## 适用与边界

没有真实图像时，宁可只用文字与留白。不生成带有虚构地标、人物身份或品牌的「氛围图」。
