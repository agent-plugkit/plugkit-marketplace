# 平涂与抠图

## 要点

- 插画用平涂色块加黑色粗描边，颜色取自色板；不用渐变和柔和的阴影。
- 照片做抠图或放在拼板墙里自己的板中，可以加一个色块背景。
- 图像与文字可以重叠，但重叠处文字仍在色块或纸面上保持可读。

## 适用与边界

没有真实图像时，用大号文字和色块撑起版面，不用占位插画充数。
