# 密度方块场

## 要点

- 唯一的主图像是落在 10px 方格上的抽象方块团：每个方块占一格，写一个等宽的密度字形 `. ' : o t x s % $ S # @ 8`。团心的字形密、底色浓，向外逐渐变稀，边缘只剩零散的 `.` 和 `'`，像一团雾或等高线的一层。
- 团块没有具象的形状：不拼成动物、人物、物件、文字、标志或箭头。轮廓是不规则的软边。尺寸按场景定：网页桌面长边约 12–20 格，海报和窄屏见 Template 的场景适配。
- 底色只用两种：团心用 `tile-ochre`，越往外越淡；外围和零散的格用 `tile-ash` 的灰阶。
- 团块待在画面两侧的边距里；海报上可以一部分压在玻璃面板背后、被玻璃虚化，网页只落在裸露的方格上（见场景适配）。直接排在方格上的文字下方，方块压到约 42% 的强度，不抢正文；玻璃上的文字不算。
- 一个画面放一到两团，团的一侧可以拖一串渐隐的短划。不把团块复制成图案，不加描边或阴影。
- 作品有真实的照片或界面截图时，放进一块玻璃，或直接作为玻璃的内容；不用库存插画、3D 物体或 AI sparkle，也不为凑图补占位图。

## 适用与边界

网页里方块团缓慢漂移，轮廓随之轻微起伏：约每 4 秒推进一段、再滑行，速度约每秒 1 格。方块始终落在格上，只改变哪些格有字形。海报画一帧静止画面，团块的位置按构图摆。没有生成脚本时，可以按上面的规则手工排一团，宁可小而准。

来源里的像素场画的是一个具体的主体。这里只取它的做法：格上方块、密度字形、两种底色、边距位置、被玻璃虚化。团块的抽象形状是推导出来的。
