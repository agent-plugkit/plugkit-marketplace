# 一个任务区一块玻璃

## 要点

- 一个任务区一块玻璃。一个画面可以有多块玻璃，块与块之间露出的方格就是通透感的来源；不把整页合成一张大卡。
- 玻璃里的子分组退化为顶部 hairline 分隔的行（无内距、无圆角、无底色）；紧贴玻璃顶边的第一行不画顶线；指标列之间用竖向 hairline。玻璃里不再放卡片。
- 可编辑、正在进行的内容放在玻璃上；只读的结果、说明和标题直接排在方格上。
- 每块玻璃最多一个墨色主按钮；次级动作是透明或淡墨洗底的 ghost 按钮。
- loading、empty、error、success 都留在所在玻璃的边界里，不另起整页或 hero。
