# 间的节奏

## 要点

- 停顿是内容的一部分：在重要的内容之前，先留出一段空白，让读者慢下来。
- 只用一个焦点；它不必很大，但周围必须安静。
- 节奏靠间隔的长短变化建立：组内紧，组间很松，章节之间更松。
- 动效（如果有）缓慢而短暂，像纸面上墨迹显现，不弹跳、不闪烁。

## 适用与边界

留白要建立层级和阅读顺序。把内容缩小后散落在空画布上，不是间。
