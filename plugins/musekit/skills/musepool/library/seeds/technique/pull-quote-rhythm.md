# 引文与段落节奏

## 要点

- 长文每隔几屏用一段引文、一张图或一个小标题打断，给读者换气的地方。
- 引文摘自正文中真实存在的句子，跨出正文栏，字号介于标题与正文之间。
- 标题、导语、正文三级字号差明显，但不追求极端反差；优雅来自比例和行距，而不是尺寸冲击。

## 适用与边界

引文只能引用原文，不改写、不编造。短内容（海报、卡片）只保留标题组与版权行；有用户提供的原文时才加一处引文，不硬造长文节奏。
