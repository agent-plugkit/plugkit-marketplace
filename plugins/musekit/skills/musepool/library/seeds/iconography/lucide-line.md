# 细线图标

## 要点

- 通用图标用 Lucide：细线、圆端点，15–16px，导航与工具方块里的图标 1.5 stroke，与相邻文字同一视觉重量。
- 纯图标按钮要有可访问名称，语义不稳定时加文字或 tooltip。
- 不手画临时 SVG，不混用填充图标族；不用 sparkle、旗帜、地球这类装饰图标充当内容。
- ASCII 字形是数据密度编码，不当图标用。
