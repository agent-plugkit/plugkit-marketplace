# 超粗怪诞体

## 要点

- 展示字用最粗的字重，紧字距、压行距，像一块实心的砖；中文同样用最粗字重。
- 正文常规字重，按钮和标签用加粗；等宽字体用于标签、编号和带「系统感」的小字。
- 允许全大写的西文标签，中文不做大小写处理。

## 适用与边界

超粗字只用在标题和按钮上；长段正文保持常规字重和舒适行距，否则整页会糊成一片。
