# 首字下沉与页眉页码

## 要点

- 一篇文章只在开头用一次首字下沉（占 `drop-cap-lines` 行），用强调色；中文首字下沉同样适用。
- 页眉或页脚放一行等宽小字：栏目名、期号或日期、页码，像杂志的书眉。
- 署名、摄影、日期放在标题下方或旁注栏，用淡墨小字。
- 引文用大一号的斜体（中文用淡墨加大字号），配一条强调色的短竖线或引号。

## 适用与边界

期号、页码只标记真实存在的顺序；单页作品不编造期号。
