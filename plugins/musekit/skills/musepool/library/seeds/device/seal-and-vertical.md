# 印章与竖排

## 要点

- 用一枚朱色小方印（边长 `seal-size`）标记一个关键信息：日期、主办方或栏目名，全画面最多一枚。
- 栏目名、署名和短标题可以竖排，从右向左阅读；竖排文字与横排正文之间留出整栏的空。
- 极细的线（1px 淡墨）只用于分开两组内容，不围成边框。

## 适用与边界

印章里的字必须真实（主办方简称、日期），不编造印文。不把鸟居、樱花、和纸纹理这类符号当作装饰堆进画面。
