# 压缝贴片与箭头

## 要点

- 每面墙（海报的一页、网页的每面墙）有一张贴片压在两块板的接缝上，海报最多两张：贴片同时盖住两块板，旋转 `sticker-tilt`，带 `rule-width` 边框、色块填充和硬阴影。它写的是最想让人记住的一件事，比如日期、「报名中」或「免费」。
- 贴片只压接缝和板的空白处，不盖住标题字形、正文和操作；在缩略图里也要看得出它是斜的。
- 分类、状态之类的小标签用同样的做法，但不旋转、不压缝，放在板内的角上：等宽字体，色块填充。等宽字体只排西文、数字和符号；含中文或长破折号「—」的值改用正文字体，因为中文落进等宽字体不再等宽，「—」在等宽字体里只占一格，看起来像短横。
- 粗线箭头、手绘感的圈和下划线用来指向一个关键信息，一个版面最多一处。
- 编号用大号等宽数字放在板的角上，像票据编号。

## 适用与边界

贴片写的必须是真实状态（日期、名额、分类），不为热闹编造「火爆」「仅剩」之类的促销话术。贴片不压在墨底板上：墨色阴影在墨底上看不见，贴片会显得没贴上去。窄屏上贴片缩小但保留旋转，整体留在视口内，不产生横向滚动。
