# 贴纸标签与箭头

## 要点

- 分类、状态和「新」「热门」之类的提示做成带边框的小贴纸：等宽字体，色块填充，可以轻微旋转。
- 粗线箭头、手绘感的圈和下划线用来指向一个关键信息，一个版面最多一处。
- 编号用大号等宽数字放在块面角上，像票据编号。

## 适用与边界

贴纸写的必须是真实状态（日期、名额、分类），不为热闹编造「火爆」「仅剩」之类的促销话术。
