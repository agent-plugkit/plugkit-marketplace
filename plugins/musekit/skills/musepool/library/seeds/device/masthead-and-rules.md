# 报头与文武线

## 要点

- 版面顶部有一条唯一的通栏报头：刊名（活动名或系列名）加一行报眉。报眉写日期、期号和地点，期号由作者编时标为示例。刊名用 `font-display`，报眉用 `font-label` 小字。
- 报头上下用文武线框住：一条 `rule-heavy` 的粗线和一条 `rule-width` 的细线并行，间隔 4px，粗线在外侧。全版只有这一处粗线。
- 报头以外，版面上没有任何元素跨满版心宽度；分「版」时用一条细横线加版名（例如「第二版 · 日程」），不再做第二个报头。
- 栏目名（「要闻」「日程」「短讯」）是墨底反白的小标签，用 `font-label`，放在稿件块的左上角；一版最多三个，只标真实存在的分类。
- 新闻式稿件的正文可以用电头开头（「示例讯」加一个空格），不写「本报讯」或任何真实报社的名称。
- 图注放在照片或数据框正下方，用 `font-label` 与 `size-meta` 淡墨；稿件署名放在正文末行，用淡墨。

## 适用与边界

不仿造真实报纸的刊名、报头字体和版式，不用哥特体、「号外」、做旧纸色。刊名用用户给的活动名或系列名；没有系列名时，刊名就是活动名，头条换成主题或最重要的一条消息。
