# 索引与分隔线

## 要点

- 章节或条目用两位数编号（01、02），放在窄栏或标题左上方，用等宽字体与 `size-meta`。
- 元数据行（日期 / 地点 / 编号 / 分类）排成对齐的表格式小栏，上方用一条细线承托。
- 编号只标记真实存在的顺序或章节，不为装饰编造序号。

## 适用与边界

图解里已经有步骤编号时，不再叠加章节索引，避免两套编号互相干扰。
