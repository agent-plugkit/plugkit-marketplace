# 象牙与酒红

## 要点

- 暖白纸面与近黑墨色承担全部阅读；强调色是一种深而沉的颜色，可以用在正文大小的文字上（栏目名、链接、首字下沉）。
- 强调色在一页里出现在几个固定的「编辑位置」上，而不是随意点缀：刊名或栏目名、首字下沉、引文标记、链接、当前态和出错说明。
- 酒红偏文学与文化；森林绿偏自然、城市与研究。

## 适用与边界

适合长篇阅读、出版、文化机构和研究报告。数据图沿用纸墨作为底色与坐标轴，强调色给被讨论的那一项。
