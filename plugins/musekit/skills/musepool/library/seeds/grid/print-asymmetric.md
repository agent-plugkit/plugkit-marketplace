# 印刷不对称栏

## 要点

- 先选一种构图家族：图像场、标本加注释、文字宣言、规线信息海报、档案图版、编辑封面、重复物件场、叠印碰撞。
- 每个画面只有一个焦点事件（超大文字、极端裁切、巨大的物体局部或一次叠印碰撞），占画面 45%–80%。
- 同时安排一块释放区：开放的纸面、浅网点或稀疏的辅助文字，占 20%–55%，让焦点有对比。
- 在 12 栏底网上分出 2–3 个宽窄不等的大区（例如 3 + 9、5 + 7、2 + 4 + 6），避免「左边一张完整照片、右边一个标题」的安全对半分。

## 适用与边界

释放区是有形状的构图，不是没用上的边距。
