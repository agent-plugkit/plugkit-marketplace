# 出血照片与一块锚定的纱面

## 要点

- 照片满幅出血，是画框的底；不裁成小图框，不留白边。
- 每个画框只有一块纱面，面积在 `veil-min` 和 `veil-max` 之间。纱面至少一条边出血到画框边缘，其余边落在栏线上；不做四边都不碰画框的悬浮面。
- 纱面的形状是矩形：竖条（跨 3–6 栏，出血到上下两边）、横带（跨满宽，出血到左右两边）、角块（出血到相邻两边）、半幅。这些是举例，不是封闭清单。
- 文字落在照片的安静处；纱面本身要跨过安静处旁边的一道明暗边界（物体边缘、地平线、拖影的末梢），让人看出照片在纱面下继续。纱面下全是均匀的天空、水面或墙时，它会读成一块实心面板。
- 纱面跨过边界的部分约占纱面面积的三分之一，这是估计，判断以「换成不透明 `paper` 后作品明显变样」为准。安静处很亮（雾、天空、水面）时，纱面要多压一些暗部；只在角上擦过一点，纱面仍会读成实心面板。
- 纱面不压主体的脸；主体的大部分落在裸露区。
- 纱面里的文字分两组：上组钉在纱面的起始端，下组钉在末端，中间留空。横带时两组分在左右两端。

## 适用与边界

画框是一件作品的一个画面：一张海报、一张卡片、网页的首屏或一章的开头。长正文和表单不进画框，排在其后的平底段落里，正文栏 6–7 栏、外边距 `margin`。窄屏上竖条放不下巨字时，改成横带：贴着安静处的那一边（上边或下边），或者只出血到左右两边、悬在画面中段，都算锚定。
