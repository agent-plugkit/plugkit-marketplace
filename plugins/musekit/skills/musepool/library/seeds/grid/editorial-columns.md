# 编辑栏与旁注

## 要点

- 正文栏宽控制在每行 60–70 个西文字符或 28–36 个汉字，通常占 6–7 栏；正文栏不与图像栏争宽。
- 正文左侧或右侧留一条窄栏放旁注、图注、署名和日期，与正文顶部对齐。
- 标题可以比正文栏更宽，横跨 9–12 栏；图像要么跨满正文栏，要么出血到版面边缘，不做中间宽度。
- 章节之间用一条细线和栏目名分开，像杂志翻页。

## 适用与边界

需要并排比较的内容（日程、价格）可以打破正文栏宽，但仍对齐到栏线上。
