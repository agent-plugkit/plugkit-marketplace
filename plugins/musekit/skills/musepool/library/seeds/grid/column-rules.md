# 栏线分栏

## 要点

- 版心等分成 `columns` 栏，栏与栏之间在栏距正中画一条 `rule-width` 的墨色竖线，这条线就是栏线。栏线从一行稿件的顶端画到底端，遇到通栏横线时断开。
- 每条稿件是一个矩形块，跨 1 到若干栏，四边落在栏线和横线上。稿件之间用一条 `rule-width` 的横线分开，横线两侧各留一个栏距，不留成块的空白。
- 版面的分量自上而下递减：头条在上半版、左上为先；短讯和日程排在下半版或最右一栏。
- 成段的正文在稿件所跨的栏里分栏续排（CSS `column-count` 等于跨栏数，`column-gap` 等于 `gutter`，`column-rule` 用栏线）；一栏排满再转下一栏，不让某一栏空出一大截。分条的内容（岗位、要目、日程）不续排，每条落在一栏上，或者在稿件里单列叠放。
- 网页上的栏线由稿件自己画：每条稿件在左侧栏距的正中画一条竖线（伪元素向左偏移半个 `gutter`），处在行首的稿件不画；上方的横线同理，处在首行的不画。各断点下行首固定时用 `:nth-child` 按断点写；稿件位置随内容变化时，用一小段脚本按 `getBoundingClientRect` 判断行首，并在尺寸变化和字体加载后重算。
- 数据框紧挨栏线时，去掉框靠栏线那一侧的边，不让两条线平行成双线。
- 版面要排满：同一行的稿件底边对齐，不留空栏。做法依次是：让短稿件多跨一栏；把一个真实的数字做成数据框，或把一句原话做成引文；把待公布事项或示例声明排成一条短讯。仍然排不满就减少栏数。不编造稿件，也不为排满改写事实。网页的稿件按内容撑高：同一行用网格让各块等高，短稿件下方留下的空白不超过约四分之一屏时可以接受，更多时把它移到别的行，或者让相邻稿件多跨一栏。

## 适用与边界

窄屏退到 2 栏；放不下两栏（每栏少于约 8 个汉字）时退成 1 栏，栏线改成稿件之间的横线，其余规则不变。数据图在一个稿件块里，图框的宽度对齐稿件跨的栏。
