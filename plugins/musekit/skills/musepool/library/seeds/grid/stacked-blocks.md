# 堆叠块面

## 要点

- 版面由带粗边框的块面拼成，块面贴着栏线排布，像一面贴满卡片的墙；块与块之间的间隙统一。
- 密度可以很高，但每块只讲一件事；最重要的块最大、颜色最亮。
- 允许一个元素打破网格：轻微旋转（不超过 3°）或错位压在另一块上，制造手工拼贴感；一个版面只破格一次。

## 适用与边界

破格的元素不能遮住核心文字和操作。表单和数据表保持规整，只在外框上体现风格。
