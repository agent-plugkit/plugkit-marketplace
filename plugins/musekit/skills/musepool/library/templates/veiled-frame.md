# 隔纱

## 精神

一张照片负责情绪，一块磨砂的纱面负责文字。纱面盖住照片里安静的那一部分，照片在纱面下继续；纱面上一个巨字点题，其余文字都很小，分两组钉在纱面的两端。没有强调色，颜色全部来自照片。读者先被照片打动，再在纱面上读到这是什么、是谁的、什么时候、要做什么。

本风格由一份四联海报参考推导而来；参考的作者与来源没有登记，所以没有范例。参考里的人名、品牌和照片不进入风格。参考用齿孔边做成票券，这只是外观之一，不是这个风格的身份。

## 文法

- **网格**：照片满幅出血，是画框的底。纱面跨整数栏，至少一条边出血到画框边缘，其余边落在栏线上。画框之后的平底段落用 12 栏，正文栏 6–7 栏。
- **对齐**：纱面里的文字从 `veil-padding` 起排，分两组：上组（巨字，加上标题或署名）钉在纱面的起始端，下组（短句，加上日期、价格或主操作）钉在末端。两组共用同一条左边线（横带时各自齐左）。
- **层级**：一个巨字和其余文字之间没有中间档。巨字之外只有粗体标题和常规正文两档；下组可以有一个 `size-figure` 的关键数字。
- **留白**：纱面中间、两组文字之间的空是有意留的，不填说明、标签或图标。裸露的照片本身就是留白，上面不放字。
- **色彩**：只有一种墨（`bright` 近黑，`dusk` 近白），没有强调色。纱面的亮暗跟着它压住的那块照片选。
- **装置**：没有装饰装置。画框外轮廓默认直角；作品本身是票、卡或藏品时可以加齿孔或圆角，它们不改变其余文法。
- **图像**：动态模糊、接近单色的摄影，照片里有一块安静区放纱面，主体和拖影落在另一侧。并排的多件作品可以拿其中一张照片放大模糊做共同的底。
- **状态**：选中时，被选条目的纱面变成不透明的 `paper`；出错时，字段下方写墨色说明，前面加「✕」这类符号，不只靠颜色；完成时，结果写在纱面上，替换原来的下组文字。焦点用 2px 墨色描边。

## 场景适配

### graphic

单页平面：海报、封面、社媒图、卡片。覆盖值按 1080 × 1440 的画布给出。

- 一张照片满幅，一块纱面。先在照片里找安静区，再决定纱面是竖条、横带、角块还是半幅；纱面面积在 `veil-min` 和 `veil-max` 之间。
- 巨字的字面宽度等于纱面内宽（纱面宽减去两侧 `veil-padding`）；竖条很窄时，巨字可以占满纱面的宽，字号按宽算，不按 `size-display`。
- 上组：巨字，下面隔一级间距排标题或署名（`size-title` 粗体，最多两行）。下组：一到三行短句，加一个 `size-figure` 的关键数字。两组之间的空至少和巨字一样高。
- 虚构示例的声明排在下组末尾，用 `size-body`。
- 系列作品共用同一个纱面位置和文字结构，换照片和巨字；多张并排展示时，拿其中一张照片放大模糊做底。
- 作品是票、卡或藏品时可以加齿孔边：用 CSS `mask` 在画框四边各叠一排半径 6–8px 的圆形缺口，缺口间距是半径的 3 倍，纱面跟着画框一起被裁。

### web

官网、落地页、商品与活动页、藏品或作品列表。参照视口 1440 × 900；平板与手机的值由 `tablet`、`mobile` 断点给出。

- 首屏是一个画框：照片满幅，高度 100svh；纱面锚在照片的安静区一侧。首屏的导航放在纱面上组的第一行（品牌和三到五个链接），裸照片上不放导航。
- 滚出首屏后出现吸顶导航条，底色是 `paper`，等于一块不透明的纱面；它和画框的纱面不同时出现在同一屏。
- 每章开头是一个画框（70–100svh），纱面的形状或位置与上一章不同（竖条、横带、角块交替）；长正文、日程和表单排在画框之后的平底段落里，底色 `paper`，正文栏 6–7 栏，每行不超过 40 个汉字。
- 列表与商品：每个条目是一个小画框，照片满幅，纱面占条目的同一位置（例如下方横带），纱面上是巨字、名称和一个关键数字。一组条目共用同一套纱面位置。
- 主操作是墨底 `paper` 字的直角按钮，放在下组末尾；每个画框最多一个。
- 窄屏退为 4 栏：竖条纱面改为贴下边的横带（出血到左右和下边），巨字按横带内宽的一半推导；照片按高度裁切，主体不被裁掉。
- 交互：悬停时纱面不透明度提高一档，过渡只写 `opacity` 和 `background-color`，160–200ms。

## 常见误用

- 纱面悬浮在照片中央，四边都不碰画框：这是通用的玻璃卡片，也会和雾面网格混在一起。
- 一个画框里有好几块纱面，纱面上再套纱面，或纱面里再放卡片。
- 在裸照片上放标题、导航或说明，或者用满幅暗色遮罩代替纱面。
- 巨字和小字之间插入中号副标题；用彩色强调按钮；加全大写的小标签。
- 纱面压住人脸或运动的主体。
- 把齿孔当成风格本身：去掉齿孔、纱面换到横带或角块，作品仍应一眼认出。
- 把照片裁成小图框，排进网格卡片。

判断方法：去掉颜色和阴影后，仍能看出满幅照片、一块锚在画框边上的纱面，以及纱面上一个巨字和两组钉在两端的小字。与雾面网格对照：雾面网格的玻璃承载任务与表单、一屏有多块、底是方块像素场而不是照片。
