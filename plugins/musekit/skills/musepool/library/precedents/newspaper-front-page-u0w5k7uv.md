# Narrative

The first issue of the Chinese daily Shen Bao (Shun Pao), dated 30 April 1872, as a scan of the printed sheet. The page carries one very large masthead set in a ruled box across the top, with the issue number and the date in two calendars flanking the title, and the whole text below it set in tight vertical columns inside ruled frames. This issue is an announcement issue: there is no news story with its own headline tiers, so the record is useful for the masthead, the column structure and the density of ruled text, not for headline hierarchy.

# Layout

The sheet holds two stacked rectangular frames drawn with a heavy outer rule. The upper frame contains the masthead and the opening text; the lower frame holds more text and has no masthead. A band of blank paper separates the two frames, so the frames read as separate blocks.

The masthead is a single full-width band at the top of the upper frame, closed below by a horizontal rule. The title sits in the center of the band. To its left, in small vertical type, are the issue number ("第一號") and the Western date; to its right is the Chinese regnal date. Nothing else shares the band, and there is only one masthead on the page.

Below the band the text runs in vertical columns read from right to left, packed edge to edge with even, narrow gaps between columns. Short pieces of text end part-way down a column and the next piece begins in the next column, so the right-hand and left-hand edges of the text block stay ragged only at the bottom of each frame.

# Typography

The masthead title is a heavy, brush-like display face set many times larger than anything else on the page, a few characters wide, and is the only large type on the sheet. The date lines beside it are set small, in the same direction as the body text.

Body text is one size of regular-weight Chinese type, set vertically with uniform spacing between characters and between columns. Short headings in the text, such as the notice titles, are set at the same size as the body and marked by position (at the head of a column, indented from the column start) instead of by size or weight. The result is a very even gray text color; hierarchy on this page comes from the masthead and the frames, not from the type scale.
