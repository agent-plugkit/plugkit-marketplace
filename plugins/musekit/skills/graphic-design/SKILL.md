# Graphic Design

让一页作品有明确的视觉焦点、阅读层级和表达目的。默认制作最终作品；仅在用户明确要提示词、方案，或工具确实不具备制作能力时停在交接材料。

## 内容 → 方向 → 制作路线 → 构图 → 制作 → 查看

1. **读懂传播目的。** 确定读者先看到什么、接着理解什么、需要记住什么。检查标题、真实信息、主体素材与展示尺寸；封面、海报和社媒共用这一判断，画幅比例由交付条件决定。
2. **选择视觉方向。** 使用用户参考、既有品牌或 seed；缺方向时由 `musepool` 提炼。按[seed 简报](../../references/seed-brief.md)选择可借细节，不把参考内容带进作品。
3. **决定什么承担作品质量。** 主体、光线、裁切、笔触或有机材质承担表达时，采用生图优先；准确文字、数据、规则几何或持续编辑承担表达时，采用排版优先；两者都不可缺时，生成视觉素材后再完成精确排版。存在准确文字不等于整张作品都应手工绘制。
4. **围绕内容建立构图。** 根据图像、文字和信息密度选择主图、文字主导或编辑分区等方法。先组织焦点和阅读顺序，再决定裁切、留白、字图关系及材质。标题长短会改变构图。
5. **完成制作。** 让工具保留本次真正借用的 seed 价值：需要摄影感、复杂材质或自然形态时使用图像生成/编辑，需要精确排版时使用布局工具、HTML/CSS/SVG，需要两者时组合。只为已选方向引入半调、印版或其他工艺。
6. **查看实际作品。** 同时检查完整画面和目标展示尺寸：标题是否读得出，主体是否可辨，信息是否准确，焦点与留白是否形成节奏。生成图像还要检查似真的品牌、地点、日期、标识和无关文字；通过编辑或独立文字层修正真实问题后再交付。

构图与工具取舍见[场景方法](references/methods.md)，完整过程见[制作示例](references/examples.md)。

## 创作自由与内容边界

- 可以自主选择布局、字体、裁切和表现手法；用户明确给定的原文、日期、身份和素材含义保持准确。
- 只采用对当前内容有帮助的 seed 特征；不为让来源“看得出来”而保留编号、网格、路线或其他会增加阅读负担的手法。
- 用户要求创作文案时可以写标题与说明。必需的真实日期、地点、价格、署名或 Logo 缺失时询问，不用伪文字、随机数字和虚构身份填满空间。
- 字图碰撞、旋转或极端比例可以使用，但不能破坏核心文字和主体。语义可辨的字体造型不因“看起来不像标准字形”而一律否决。
- mono-color 是一种可选的印刷语言。有限色、纸面和油墨角色只在选择这一方向时生效，不作为所有平面作品的默认规则。

## 交付

交付图片或用户要求的成品格式；有可编辑源文件时一并保留。说明关键设计选择和实际检查结果。使用图像生成时保留最终提示词供复用，无需输出编译 manifest。
