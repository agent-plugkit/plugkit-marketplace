# 平面结构原型

结构原型回答「这一页需要哪些区域、按什么顺序读」。先按内容选原型，再用 style.md 的文法和本场景适配决定区域占几栏、对齐在哪、留白落在哪里。同一原型在不同风格下会长得完全不同。

画幅是交付条件。横版、方形和竖版都可以使用这些原型；换画幅时重新安排区域，而不是只裁掉边缘。

## 主图主导

一张照片或一个主体承担故事。

- **区域**：主图（占画面一半以上）、标题、信息区。
- **阅读顺序**：主图 → 标题 → 信息。
- **密度**：低，信息区只放必需事实。
- **关键判断**：裁切决定张力，保留主体的关键特征；标题与主图背景要分得开。

## 文字主导

一句话就是主题，或者没有合适的图像。

- **区域**：标题字块（即主视觉）、导语或副标题、信息区。
- **阅读顺序**：标题 → 导语 → 信息。
- **密度**：低到中。
- **关键判断**：断行和字号建立节奏，标题长短会改变整个构图；次要信息聚成整齐的块。

## 编辑分区

多组内容都需要被读到，例如节目单、日程、多位嘉宾。

- **区域**：标题区、若干内容分区、信息区。
- **阅读顺序**：标题 → 按重要性排列的分区 → 信息。
- **密度**：中到高。
- **关键判断**：分区之间要有权重差，每个分区有自然的入口；不要把所有分区做成同样大小。

## 系列

一组社媒图或多张海报。

- **区域**：每张沿用同一套区域位置，变化区放每张的独立内容。
- **阅读顺序**：单张能独立读懂。
- **关键判断**：共享网格、标题位置和信息区位置；变化来自内容本身，而不是机械重复同一构图。
