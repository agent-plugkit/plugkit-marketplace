# 平面制作示例

五份示例用同一条流程做同一类任务：一张 1080 × 1440 的社媒竖版活动海报。前三份没有照片，只有文字信息；后两份的风格离不开照片，先生成照片、核对照片，再排版。风格不同，结构就完全不同。读它们是为了学**判断过程**：怎样从 Brief 和 style.md 推出区域与栏位，评审查出了什么、怎样修正。不照搬构图、坐标和文案；换一个风格或换一份内容，结论都要重新推导。

| | [新粗野主义：《造物集市》](examples/neo-brutalism-maker-fair.md) | [编辑衬线：《长河》春季号](examples/editorial-serif-long-river.md) | [日式留白：「窑开」开窑日](examples/japanese-ma-kiln-opening.md) |
| --- | --- | --- | --- |
| 读者要先记住 | 活动名和「报名中」 | 本期主题「水边的人」 | 活动名「窑开」 |
| 结构原型 | 文字主导，借编辑分区的列表板 | 文字主导 | 文字主导 |
| 层级靠什么 | 面积悬殊：主板压倒其余小板，标题用 `fit` 顶满主板 | 字号阶梯和中轴：标题直接用 `size-display`，下面的字一级级变小 | 位置和尺寸：竖排标题用 `fit --vertical` 占可用高度的 58%，其余退到对角 |
| 留白在哪 | 墙内不留缝；主板下部留一条空带给贴片 | 标题组与页脚之间的大片纸面 | 标题与信息组之间的大片纸面，约占画面四分之三 |
| 颜色 | 三块色板加一块墨底，贴片用第二强调色 | 强调色只用一处（书眉刊名） | 纸墨之外只有一枚朱色印章 |
| 评审改得最多的 | 下半部两块板等宽等高，不够悬殊 | 示例标注太小、小标把句子挤偏中轴 | 印章离信息组太远、副题与标题的墨迹没对齐 |

| | [隔纱：栖苇植物园春季开放日](examples/veiled-frame-spring-garden.md) | [暗场：「冬夜篝火朗读会」](examples/dark-stage-fireside-reading.md) |
| --- | --- | --- |
| 读者要先记住 | 巨字「春」和风里的玉兰 | 字标「篝火」和后面的火光 |
| 结构原型 | 主图主导 | 主图主导 |
| 层级靠什么 | 纱面里的巨字压倒其余文字，标题和事实钉在纱面上下两端 | 一个横跨画面的字标，下缘被前景的倒木压住；其余小字只有一个字号，贴着四边 |
| 留白在哪 | 纱面里上下两组之间的大段空 | 暗部就是留白，画面中间只有场景和字标 |
| 颜色 | 照片的灰绿和花色，版面只有纸和墨 | 近黑的底和暖白的字，强调色只有火光的橙 |
| 评审改得最多的 | 纱面大半盖在一片均匀的雾上，重生成照片让枝条伸进纱面；删掉与日期重复的关键数字 | 没有实质问题；照片在动手前的审图里退回过一次（前景只是一条地面坡线） |

前三份示例是风格验收或盲测时做的，后两份是风格验收之后专门为风格库做的；评审都走了完整档（空白上下文评审者，多轮复查），Brief 和栏位表也为了讲清判断过程写得很全。正式制作默认走[默认档](../../../references/critique.md#默认档)；Brief 写在对话里，栏位决定在交付说明里用几句话交代就够了。

五件作品都在 Brief 里把可创作内容标成示例，把用户没给的事实（报名方式、网址、联系方式）留在海报之外。做真实作品时，示例标注换成真实内容即可。

前三份走排版优先：没有图像素材，质量来自字形、尺度和网格。后两份走混合路线：照片由生图工具生成、不含文字，文字全部在 HTML 的排版层；照片在排版前先按风格的图像要求核对（安静处与明暗边界、可抠的暗剪影前景），不合格就重生成。路线怎样选见[制作路线](methods.md)。
