# 平面制作示例

两份示例用同一条流程做同一类任务：一张 1080 × 1440 的社媒竖版活动海报，没有照片，只有文字信息。风格不同，结构就完全不同。读它们是为了学**判断过程**：怎样从 Brief 和 style.md 推出区域与栏位，评审查出了什么、怎样修正。不照搬构图、坐标和文案；换一个风格或换一份内容，结论都要重新推导。

| | [新粗野主义：《造物集市》](examples/neo-brutalism-maker-fair.md) | [编辑衬线：《长河》春季号](examples/editorial-serif-long-river.md) |
| --- | --- | --- |
| 读者要先记住 | 活动名和「报名中」 | 本期主题「水边的人」 |
| 结构原型 | 文字主导，借编辑分区的列表板 | 文字主导 |
| 层级靠什么 | 面积悬殊：主板压倒其余小板，标题用 `fit` 顶满主板 | 字号阶梯和中轴：标题直接用 `size-display`，下面的字一级级变小 |
| 留白在哪 | 墙内不留缝；主板下部留一条空带给贴片 | 标题组与页脚之间的大片纸面 |
| 颜色 | 三块色板加一块墨底，贴片用第二强调色 | 强调色只用一处（书眉刊名） |
| 评审改得最多的 | 下半部两块板等宽等高，不够悬殊 | 示例标注太小、小标把句子挤偏中轴 |

两份示例都是风格验收时做的：评审走了完整档（空白上下文评审者，多轮复查），Brief 和栏位表也为了讲清判断过程写得很全。正式制作默认走[默认档](../../../references/critique.md#默认档)；Brief 写在对话里，栏位决定在交付说明里用几句话交代就够了。

两件作品都在 Brief 里把可创作内容标成示例，把用户没给的事实（报名方式、网址、联系方式）留在海报之外。做真实作品时，示例标注换成真实内容即可。

## 制作路线

两份示例都走排版优先：没有图像素材，质量来自字形、尺度和网格。路线的判断方法见[制作路线](methods.md)，下面是三条路线在本流程里各自多做什么。

- **排版优先**：按 style.md 的 `:root` 和字体做固定尺寸的 HTML，展示字按适配要求用 `fit` 推导或直接取 token，用检查脚本导出 PNG（它等字体加载完成再截图）。风格专属的度量，比如墨迹宽、对齐轴和面积比，脚本不量；规则写了具体数值时，再写几行代码量它。
- **生图优先**：画面的感染力来自人物、场景、光线、笔触或印刷质感时，直接生成完整作品。提示词写主体关系和表达意图，再把 style.md 的配色、手法和常见误用翻成画面要求，例如「两种墨色、机械网点、留一块安静纸面」；不写坐标。短文字生成后逐字核对，并检查画面里没有似真的品牌、地名或日期。交付时附最终提示词。
- **混合**：图像质感和准确文字同样重要时，先生成无字主视觉，再在独立的排版层按 style.md 的网格排文字。评审时看两层是否像同一件作品：焦点、遮挡和色彩是否一致，主视觉是否给标题留出了位置。
