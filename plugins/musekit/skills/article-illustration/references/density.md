# 关系图的密度

密度只用于关系图：Mermaid，以及从散文抽出的流程、架构、状态和因果。它描述这一张图里必须读准的文字、分支和关系，不是全文配几张图。

## 低密度

下面四项同时成立，才可以尝试生图：

- 标签只有少量短词
- 关系是单一方向
- 没有条件分支、异常路径和回路
- 没有必须精确的数字

例如「收集 → 整理 → 展示」三个短标签、一条方向。确认配图方案，就等于明确选择这一张走 `diagram-design` 的图像方式。制作时读取该 Skill 的图像说明，不先做 HTML 再截图。

[plan_article.py](../scripts/plan_article.py) 只根据 Mermaid 的结构给建议。它把「少量短词」读成 1 到 6 个标签、每个不超过 8 个字符，且不含空白或句读；分支是同一节点有多条出边，或时序图里的 alt / else / opt / par；回路包含回到先前节点的边，以及 loop / critical。分组、精确数字也建议走可编辑图解。散文图位不由脚本新增。确认前可以改建议。

## 高密度

四项里出现任何一项，就直接做可编辑 HTML 图解，再导出 PNG。带分支和回路的架构图走这条路径。

## 核对与退回

打开生图结果，核对必须保留的标签和方向。必须的文字错了，或方向画反了，就改做结构化图解。这张位图不插入文章，提示词可留在 `sources/` 供对照。

题图和示意插画不读这份清单，它们按 [图位](slots.md) 交给 `graphic-design`。带必须核对的数值、且文中有表格或数据文件时，走 `scientific-figure`，不因为点少就改成生图。
