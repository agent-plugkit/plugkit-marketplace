# 图位与路由

先收集必做图位，再判断是否新增。不按文章类型预留封面、每节或文末槽位，也不设张数上限。

## 必做

每个非空 Mermaid 围栏都是图位。不跳过，不合并，不改写围栏里的关系。空围栏跳过。

## 可以新增

命中下面任一条才新增：

- 用户明确要求封面、题图或某一处配图
- 读者要同时看清两侧的对比
- 流程、结构或因果写在散文里，文中还没有围栏
- 抽象论点可以收成一张带少量标签的图

不新增这些：

- 把比喻画成字面物件
- 为每个标题补一张
- 把已经写清的段落再画成氛围图
- 用文中没有的数字做统计图

从散文抽出关系时，只使用原文已有的步骤和条件。大纲记下对应原句，确认时用户能对照。

作者原文里已有的图片保留，不重新生成，也不算新图位。

## 路由

| 图位 | 场景 Skill | 路径 |
| --- | --- | --- |
| Mermaid，或散文里的流程、架构、状态、因果 | `diagram-design` | [密度](density.md) |
| 封面、题图、单一视觉隐喻 | `graphic-design` | 该 Skill 自己的规则：准确文字用排版，摄影和材质用生图 |
| 文中有表格或数据文件，图要呈现这些数据 | `scientific-figure` | 不生图，不补造数据 |
| 正文里只有两三个数字，没有表 | 不新建数据图 | 数字留在文字里，或作为关系图标签 |

封面和数据图不使用关系图的密度清单。
