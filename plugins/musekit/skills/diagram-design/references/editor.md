# 成品中的布局编辑

在桌面 Chrome 或 Edge 打开自包含 HTML，默认是阅读模式。点击画布外的“编辑布局”，工具栏、属性面板和选中边框与作品样式隔离，也不会进入 PNG。全部操作可离线完成。

## 属性面板与窗口布局

属性面板分为当前对象属性、主体与画布、布局提示，以及独立滚动的对象与连线列表。选择对象后显示名称、类型和 ID，先调整位置、尺寸或连线；“主体与画布”可折叠。列表优先显示节点名称和连线标签，附带 ID 或端点，长名称可悬停查看。切换对象后选中项保持可见，滚动列表不会带走上方属性；输入数值后直接选择另一个对象会先提交当前修改。

宽窗口使用右侧面板，窗口宽度不超过 900px 时改为底部双栏，属性与对象列表各自滚动。工具栏可换行，缩放与保存状态移入底部面板标题栏。“适合窗口”根据工具栏和面板实际占用空间显示完整画布；处于适合窗口状态时跟随窗口大小调整，手动缩放或空格拖动后保留当前视图尺度。面板折叠、滚动和焦点只影响本次查看，不写入布局历史或导出作品。

## 模块与分组

- 点击模块单选，Shift 点击多选；可从右侧对象列表选择嵌套分组与时序行，Alt 点击选中父分组。
- 拖动模块，或按方向键移动 1px、Shift + 方向键移动 10px。右下角方形手柄调整尺寸，属性面板也可输入宽高和位移；文字不缩放，尺寸不能小于内容。
- 多选后可左对齐、顶对齐、水平或垂直等距分布。选择父分组及其子节点时，移动只应用一次。
- 分组移动带动标题、子节点、注释与内部路径。分组调整尺寸只改变容纳空间。主体顶部间距及“整体下移 24px”用于整体避开页眉，画布和页脚随内容增长。
- 时序参与者只横向移动，生命线与消息端点同步。选择消息行调整纵向位置；上下消息限制移动范围，保持顺序与分支归属。

## 连线与标签

点击连线后，拖动标签框或编号折点。折点从连线起点依次编号，右侧面板用相同编号和各自的“×”对应：点击编号定位并高亮折点，点击其旁边的“×”只删除这个控制点，剩余编号随之更新。删除可撤销、重做，保存 HTML 后保留结果；删除按钮也可用 Tab 聚焦、Enter 或空格触发。

属性面板可切换出入端口的边、调整端口比例与标签偏移；“增加折点”用于拉出新的线槽。“恢复自动走线”清除该连线的手工点，“恢复标签位置”清除标签偏移。端点始终绑定原节点。

开始编辑自动路径时，现有转角可作为控制点调整。增删或拖动后，编号对应保留下来的控制点；为连接端口或维持正交而自动补齐的转角不会重新编号成已删除的控制点。删除最后一个控制点后交给自动走线，仍可能保留避让内容所需的转角。

移动节点后，手工折点保留，代码补齐与端点的正交连接；如果该路径穿过其他内容，会高亮提示，编辑器不会擅自重新排列整张图。时序消息由参与者和消息行决定端点，不提供改变业务关系的操作。

直线由两个端点决定，通过移动节点或调整端口改变路径，不提供中间折点操作；标签仍可独立调整。

## 查看、历史与问题

缩放按钮、空格拖动平移和“适合窗口”只改变查看方式。一次拖拽记作一次历史记录；Ctrl/Cmd + Z 撤销，Ctrl/Cmd + Shift + Z 重做。历史保留最近 100 次操作，重开文件后从保存的布局开始新的历史。

布局提示覆盖溢出、模块重叠、标签遮挡、连线穿过无关节点、页眉侵入与越界。点击提示选中并定位对象。分组容纳子节点、标签覆盖自己的线段属于正常表达；提示不判断信息是否完整、色彩或字号是否合适。有提示时仍允许保存 HTML。

## 保存与 PNG

“保存 HTML”下载新的可编辑文件，保存当前布局和编辑能力；打开下载文件即可继续。不覆盖原始文件，也不依赖浏览器缓存。建议保留原件；浏览器可能为重复下载自动添加文件名后缀。

“导出 PNG”默认 2 倍分辨率，可选 1 倍，导出完整画布，与查看缩放和平移无关。导出不含工具栏、面板、选中边框或提示覆盖层。超过 16,384 像素单边或 64,000,000 总像素时拒绝导出，建议选择 1 倍或减小画布；资源加载失败或对象越界也会明确报错，不下载截断文件。

首版只微调位置、尺寸、间距和走线。文字、样式、节点数量、业务关系与原始 `.mmd` 的修改仍由制作源文件负责。关闭尚未保存的页面会失去本轮调整。

## 查找与阅读关系

阅读模式点击“查找节点”或按 `/`，按名称、ID 或正文查找。上下方向键在结果间移动，Enter 选择；搜索框内不抢占输入。结果同时显示名称和 ID，重名节点不会合并。没有匹配时显示空结果。

选择结果或直接点击普通节点后，画布保持当前缩放，将节点定位到面板之外。覆盖层标出节点、直接关联线和对端，作品原色与完整内容保留。面板分别列出入边、出边、无箭头关联和自循环；无关联节点也会明确说明。无标签显示“未标注关系”，时序中的重复消息分别显示。

关闭按钮或 Escape 关闭并恢复焦点。进入编辑布局时关闭阅读面板；阅读不会新增撤销记录，也不写入保存 HTML、PNG、URL 或浏览器存储。阅读功能不提供路径搜索、传递影响判断或链接分享。

布局提示按“错误”和“提示”分组；点击定位具体问题区域，并显示关联对象、实测距离或连续长度与可用修复方向。它不会自动移动对象。提示不阻止保存或既有 PNG 导出；验证后交付的门槛见[制作说明](html.md#验证后交付)。
