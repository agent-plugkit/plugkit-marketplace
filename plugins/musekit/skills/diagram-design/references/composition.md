# 图意决定组织方式

图解可以采用编辑版面、空间隐喻、图形关系或它们的组合。先判断读者要追踪什么，再从这些方法起步；不按节点数量套统一模板。

| 图意 | 一种有效起点 | 必须仍能读到的关系 |
| --- | --- | --- |
| 系统架构 | 按职责分栏或分区，分配主次面积；跨区接口单独留出走线带 | 系统边界、接口来源与去向、反馈回路；不能只有组件名单 |
| 决策过程 | 按判断阶段组织，优先规则、命中结果和未命中路径分别呈现 | 判断条件、先后顺序、所有出口与回到哪一步 |
| 交互时序 | 参与者作为泳道，消息沿时间方向展开；分支作为独立事件区 | 请求与返回、消息顺序、自调用、分支条件与备注 |
| 状态迁移 | 突出活跃状态，按转换含义组织去向，回路获得独立空间 | 源状态、目标状态、触发条件、初始/结束含义与自循环 |

## 从内容得到版面

先用用户给定的实际文字估计内容重量。长说明与短标题需要不同空间；分支多的区域需要更大面积或更长阅读路径。大标题、索引、图例和注释也属于版面，不能最后叠在节点上。

决策图可以使用规则行而不画菱形：将“满足条件 → 结果”“否则 → 下一规则”明确写在对应位置。架构图也可用接口条带代替漫长折线，只要每条条带清楚标出来源、去向和含义。重组表达时逐项核对来源，不能用漂亮的组件分栏省掉连接关系。

## 把精美落到具体决定

- 用字号、字重和位置形成第一眼入口，再通过分区标题建立第二层阅读。
- 颜色承担职责，例如区分主流程、例外与回路；细线、直接标签和空间关系共同帮助读者追踪。
- 允许不同节点具有不同形态、插画或面积，前提是它们的内容权重与职责值得这种区别。
- 留白控制章节节奏，也给连线与说明留出空间。它不等于把节点缩小后散落在大画布上。
- 系列图可共享视觉语言，同时根据图意改变结构。架构、决策和时序不需要长成相同的卡片网格。

## 密度与拆分

先尝试改变阅读方向、换行、区域比例或关系表达，再考虑扩展画布。固定尺寸下仍难以阅读时，给出具体的拆分建议：总览包含哪些系统，哪一部分进入详图，跨图关系如何标识。待用户确认后拆分，保留原始完整来源。

不能通过删掉异常分支、把多条条件合为“其他”、藏掉标签或无限缩字来声称解决了密度问题。
