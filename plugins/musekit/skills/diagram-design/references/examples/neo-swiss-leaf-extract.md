# 新瑞士国际主义：叶片提取与并行检测（实验报告插图）

把一段实验步骤做成插进 A4 Word 实验报告的流程图，风格取新瑞士国际主义的钴蓝变体。学这份示例的判断过程：画布宽度怎样从显示宽度和最小字号倒推，风格的编号细线骨架怎样落到一张小画布上，黑白打印时怎样不只靠颜色分清主路径。不照搬坐标；换了内容，分区、栏位和线型都要重新推。

[制作源文件](source/neo-swiss-leaf-extract.html)和[可编辑成品](neo-swiss-leaf-extract.html)：源文件未内嵌运行时，接法见[接入示例](../integration.md)；成品可以直接在浏览器里打开、查找节点和微调布局。

## 请求

> 帮我把下面这段实验步骤做成一张图，放进实验报告里（报告是 A4 竖版的 Word 文档，图会缩放到正文宽度）。风格用新瑞士国际主义（`neo-swiss`），直接做，不用问我。
>
> 取 0.5 g 叶片样本，加入 2 mL 提取缓冲液后研磨。研磨液在 4 °C 下以 12 000 rpm 离心 10 分钟。离心后分成两部分：上清液转移到新管，进入后续检测；沉淀弃去。上清液分成两份并行检测：A 份做蛋白浓度测定，B 份做酶活性测定。两项结果汇总到同一张记录表。

## Brief

- **读者想弄清什么**：审阅者和复现实验的人想知道「实验怎样进行，物料去了哪里」，对应结构原型「科学过程示意」。阅读顺序：样本与缓冲液 → 研磨 → 离心 → 分流（上清液留下，沉淀弃去）→ A、B 两份并行检测 → 汇到同一张记录表。
- **核对清单**：9 个实体（叶片样本、提取缓冲液、研磨、离心、上清液、沉淀、A 份、B 份、同一张记录表）和 9 条关系。逐字准确：`0.5 g`、`2 mL`、`4 °C`、`12 000 rpm`、`10 分钟`、「转移到新管，进入后续检测」「弃去」。三条最容易画错：只有上清液进入后续，沉淀一路要画出但不连向任何后续；A、B 是并行，不是先后；两项结果进的是同一张表。
- **在哪里被看到**：A4 竖版 Word，缩放到正文宽。实验报告多半要打印，而且可能是黑白：最小字缩放后不小于 7 pt（约 9.3 px），主路径、弃去和并行要靠线型、位置和文字也分得清。Word 通常自带「图 1 …」图注，用户没说有没有，所以图内只留一行短图题和「概念示意」，交付说明写明图题可删。
- **来源缺口**：A、B 各取多少、上清液转移的体积、研磨方式与时长、两项测定的方法、缓冲液成分、记录表字段，离心只给了 rpm 没给离心力。用户要求直接做，全部列进交付说明，图上一项不补。
- **成功标准**：核对清单全部在图上且数值逐字一致；按正文宽黑白打印时最小字不小于 7 pt，三种线分得清；去色后凭强左轴和编号细线骨架认得出新瑞士，而不是居中的等大卡片流程图。

## style.md 里起决定作用的部分

- **变体**：用户只点名了风格，变体由制作方选。强调色要给主路径，而实验报告里红色常被读成危险或报废；style.md 说钴蓝「更冷、更像机构与档案」，和实验记录更贴，所以选 `cobalt`，不用默认的信号红。
- **本场景适配**，每条都落到了版面上：
  - 「每个分区顶部一条细线，线下是两位编号和分区名」：得到左侧编号栏加通栏顶线的行式骨架，这是它和普通流程图差别最大的地方。来源的步骤本身没有编号，所以可以加 01–05，只标阅读顺序，并在来源说明里声明是制作方添加的。
  - 「分叉与汇合节点横跨它的所有分支，左缘仍在轴上」：定下研磨、离心、上清液、记录表的宽度。
  - 「辅助区退到窄栏」：沉淀放进右侧窄栏。
  - 「强调色只给一处：主路径的线」「例外用墨色虚线或 `ink-muted` 细线，不用第二种彩色」：定下线型方案。
  - 「图题用 `size-title`，不用 `size-display`」：层级只有 28 / 17 / 13 三级，尺度反差弱，风格主要靠网格和骨架撑住。
- **基线节奏**和**常见误用**：间距和内边距取自阶梯，固定画布上区块起点落在 8 的倍数；「去掉颜色后仍能凭网格和尺度认出」直接写成了成功标准的第三条。

## 结构与构图

图型是[科学过程示意](../structures.md#科学过程示意)：从上到下五个分区，01 制备、02 离心、03 分离、04 并行检测、05 汇总。

**画布宽度**：按[信息与空间](../../SKILL.md#信息与空间)反推，正文宽取两种常见页边距里较窄的一档。左右各 2.54 cm 时正文宽 15.9 cm（约 600 px），中文 Word 默认的各 3.18 cm 时是 14.6 cm（约 553 px）。最小字是 `size-meta` 13 px，要求 13 × 553 ÷ W ≥ 9.33，得 W ≤ 770，取 768。这样 600 px 下最小字约 7.6 pt，553 px 下约 7.0 pt。高度不固定，由内容撑到 1024。网格随画布重推：token 按 1440 宽给出，768 宽的画布上字号照用 token，`margin` 取阶梯上的 48，`gutter` 保留 24，12 栏，栏宽 34。

| 区域 | 栏位 | 内容与形态 |
| --- | --- | --- |
| 页眉 | 从左轴 x = 48 起 | 图题 `size-title` 半粗；副题「概念示意 · 图形大小不代表实际用量」，`size-meta` 淡墨 |
| 编号栏 | 第 1–2 栏 | 等宽 `01`–`05` 加半粗分区名；每个分区顶上一条通栏细线 |
| 01 制备 | 物料各 5 栏，研磨 10 栏 | 样本、缓冲液不加框，文字压在一条细线上；研磨是直角细线框，横跨两项输入 |
| 02 离心 | 10 栏 | 不写节点标题（分区名已经是「离心」），只放温度 / 转速 / 时间三列条件表 |
| 03 分离 | 上清液 8 栏，沉淀 2 栏 | 上清液细线框；沉淀墨灰虚线框，标「弃去」 |
| 04 并行检测 | A、B 各 4 栏，右侧 2 栏空 | 两个同形细线框，同一行等高 |
| 05 汇总 | 8 栏，右侧 2 栏空 | 记录表墨底纸字，全图最重的块，是视觉终点 |
| 页脚 | 从左轴起 | 图例只解释两种线 |

主体 10 栏的左缘全部压在第 3 栏起点这一条竖轴上，分叉与汇合节点向右跨满它的分支；04、05 行右侧留出成块的空栏，整版不居中、不镜像。节点形态按角色分四种：投入物料、操作与中间产物、弃去、终点。条件表的列起点对齐图上已有的竖轴：「转速」对齐缓冲液的文字，「时间」对齐沉淀框左缘。

**线型与颜色**：钴蓝 2 px（`rule-state`）只给样本主路径，即样本 → 研磨 → 离心 → 上清液 → A、B。「加入」和两条「结果」用墨色 1 px，由连线标签说明；结果不是样本物料，所以不用蓝。弃去用 `ink-muted` 1 px 虚线。图例只列「样本主路径」和「弃去的一路」，另两种线的含义由标签自带。

## 制作

按[制作说明](../html.md)写 HTML：DOM 和 CSS 负责全部文字与样式，`:root` 只放 style.md 的 token；关系 JSON 声明 9 条连线，设 `portDistribution: "spread"` 与 `layout: "tidy"`。

- 节点按栏显式设宽（物料各 5 栏，研磨和离心各 10 栏），整理时不必再改宽度，网格不会被挪动。A、B 的进出口写 `"at": 0.5`，两条并行支路都落在各自框的中点。
- 数值包在 `white-space: nowrap` 里，「12 000 rpm」不会断开。正文开 `tabular-nums` 让数字等宽；「10 分钟」含中文，不能改用等宽字体。`tracking-meta` 只给等宽编号，中文小字不放字距。
- style.md 之外的值都写进交付说明：画布 768 × 1024、外边距 48、栏宽 34、条件表列宽 273 / 174，以及字体栈里补的本地名 `Source Han Sans CN`（Seed 允许印刷导出用思源黑体的本地版本）。

要重新得到可编辑 HTML 和 PNG，把源文件复制到装有 Playwright 的作品目录、改名为 `leaf-extraction.source.html`，从那里运行交付命令（脚本路径换成本 Skill 的实际位置）。先装好 style.md「字体」一节列出的字体，否则按字体栈回退。

```sh
node scripts/deliver_diagram.mjs leaf-extraction.source.html --output leaf-extraction.html --strict --json
```

通过后 `leaf-extraction.html` 是离线可开的可编辑成品，PNG 在 `leaf-extraction.checks/<批次ID>/`。`--strict` 让布局提示也阻断交付；最终批次没有错误，也没有提示。

## 评审发现与修正

评审走[完整档](../../../../references/critique.md#完整档)：制作方先按默认档自查，再把 Brief、style.md、成品、检查报告和 600 / 553 px 缩放图、灰度图交给空白上下文的评审者，共两轮。

| 发现 | 修正 |
| --- | --- |
| 自查：上清液最初不加框，主路径箭头落在空白处 | 加细线框，箭头有了落点 |
| 自查：去色后「加入」线和主路径在图例里分不清 | 图例收为两项 |
| 自查：「研磨液」标签压在下一分区的顶线上，纸色衬底把顶线切断 | 01 分区加高到 248，标签落到顶线上方 |
| 「结果」线也是蓝色，图例「样本主路径」名不副实；蓝线去色后又偏浅 | 结果线改墨色 1 px，蓝色只留给样本流 |
| B 份的进出线延续上方主干，偏离 B 的中点；B 像主干、A 像旁支，削弱了并行 | A、B 的进出口都落在各自中点 |
| 离心条件表的「转速」「时间」不在任何已有竖轴上 | 调列宽，分别对齐缓冲液文字和沉淀框左缘 |
| 节点内边距 12、标签内边距 6 不在阶梯上；分区起点不在 8 的倍数上；中文小字套了 `tracking-meta` | 内边距改 16 和 `0 8px`；分区起点改为 144 / 392 / 528 / 664 / 808；中文小字的字距归 0 |
| 字段名、副题和图例是制作方加的文字，来源说明里没声明 | 来源说明补上「制作方添加的文字」 |
| 分区名「离心」和节点标题「离心」并排重复 | 节点去掉标题，只留条件表 |

第一轮没有实质问题，以上都是次要问题；第二轮确认已修正，改动波及处没有新问题。保留了三项，都写进交付说明：

- **钴蓝去色后约 #626262，比墨线还浅**。黑白打印时主路径不是最重的线，要靠 2 px 线宽、图例和另两种线上的标签区分。成功标准只要求分得清，所以保留，同时给出替代：确定只黑白打印时，把主路径改成墨色 2 px。
- **553 px 下最小字约 7.0 pt，刚好达标，没有余量**。交付说明写明插入 Word 时宽度不要小于 14.6 cm。
- **无框物料的文字比框内文字靠左 16 px**。框有内边距，这是两种节点形态的固有差别，评审者接受保留。
