# 几种可选视觉方向

这些方向帮助理解色彩、字体与空间如何共同工作，不限定可用风格。已有用户参考或 seed 时直接使用它；不必套入下面的名字。根据内容调整比例、节点形态与强调方式，不要求每张图使用同一模板。

## Swiss Style

采用现代编辑型 Swiss 的清晰、秩序与轻盈：以模块网格组织信息，用常规或较轻字重建立大尺度标题，少量强调色配合中性背景。钴蓝是一种选择，实际颜色可来自用户或 seed。细分隔线、章节索引和留白可以成为构图骨架；编号只有在有助阅读且不会被误认为来源数据时添加。

可用明确的列、行或跨栏区域建立秩序；跨栏和尺寸变化表达主次。一块大面积强调色可以成为章节锚点，其他区域保持克制、平整。网格帮助组织内容，不要求所有节点长得相同。

只套用“白底 + 蓝色按钮”或同尺寸卡片，通常不足以建立这类风格。关注比例、字重、间距和精确对齐，避免每个区域都用强烈色块与粗体争夺注意力。

## Neo-Brutalism

核心是直接、有力、略带挑衅。粗边框、硬阴影、撞色块、超大文字和有意的不完美可以同时出现；节点可以像贴纸、标签、窗口、路牌或实体物件。构图可以跳跃，但关系线与阅读顺序必须坚决清楚。

不要把“粗黑框 + 随机鲜艳颜色”当成完成。夸张要有主次，阴影、倾斜与装饰不能压过文字，也不能让每个节点都争夺最高注意力。

## JAPANESE MA

核心是间、停顿与含蓄的张力，但信息图首先必须可读。先为内容安排区域，再让留白承担分组和节奏；少量墨色、纸色与朱色是一种选择。细线、轻微不对称、局部垂直文字或印章式标记都可以使用，前提是内容边界与阅读顺序仍然清楚。

节点可以弱化容器感，却不能只靠过大的距离或抽象隐喻让读者猜测关系。不要把它做成“极简模板”，也不要堆砌樱花、鸟居、和纸纹理等文化符号。留白必须建立层级和线槽，而不是简单把内容缩小后散落在空画布。

## 混合与取舍

让字号、色彩、形态和间距形成协调的视觉语言。可以结合参考：例如在编辑网格中用一个有力的实体标签突出关键决策；判断依据是内容是否更易读、重点是否更明确，而不是风格名称是否纯粹。

## 让风格改变信息的呈现

先把参考翻译成信息组织决定，而不是 CSS 参数。强对比、大字或纸张感分别要解决什么阅读问题？在落坐标前比较两种适合当前内容的组织方式，选择更能说明关系的一种。无需交付长篇设计分析，但要能说明选择理由。制作示例用于学习接入与图意表达，不是换风格时必须保留的版面。

| 需要重新决定的内容 | 可观察的变化 | 不能单独证明风格迁移的变化 |
| --- | --- | --- |
| 阅读入口与空间组织 | 重心、阅读轴、分区比例或阶段组织改变，并帮助读者追踪内容 | 原布局只改色值、画幅或外边距 |
| 节点角色与信息层级 | 输入、关键处理、判断、终态与旁注具有合适的面积、位置或形态差异 | 所有卡片统一加粗边框、阴影或换字体 |
| 关系表达与节奏 | 主路、支路、回流和注释有明确空间职责，标签与所属关系一起安排 | 用装饰箭头、编号或口号填满空白 |

时序图的泳道与时间顺序、状态图的迁移含义仍须保留；变化可以发生在事件分区、角色层级、分支空间和注释组织，不为求新打乱事实。将不同风格的成品按相同显示宽度并排查看：即使暂时忽略颜色，也应能指出有内容理由的构图和表达差异。

风格迁移与精美度分别判断。实际查看 PNG，检查第一眼入口、主次尺度、文字对比、空白用途和沿线阅读；程序检查通过不能替代这一步。大块空容器、重复的技术标签和印在图上的制作口号不自动产生设计质量。所有新增说明都要能追溯到来源，不能为了填充版面补造缓存、通知、重试策略或服务保证。

深浅色块混排时，沿整条路径检查线条、箭头和起止标记与背景的对比；标签可读不代表连线可见。必要时调整通道、描边或色块边界，让路径经过不同背景时仍能连续追踪。
