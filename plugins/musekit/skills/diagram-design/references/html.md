# 自定义 HTML/CSS/SVG 制作

制作独立图解作品：DOM/CSS 拥有文案和视觉，共用代码拥有测量、连线、诊断和布局编辑。Musepool 的 seed 简报决定视觉方向，不参与几何计算。

## 一次完整制作

1. **组织内容。** 读取语义来源，选择适合图意的构图。先安排页眉、主体、页脚、注释和回路通道；系统分栏、规则行、泳道与状态分支各自保留不同结构。
2. **完成文字排版。** HTML 使用 Grid、Flex 或绝对定位安排初始构图，节点设置内容宽度、内边距、字号和行高，高度优先自适应。中文正常换行，长代码用 `overflow-wrap:anywhere`；无需断行的短标识可以 `nowrap`，但必须给足宽度。SVG 用 `tspan` 显式分行，不依赖浏览器自动换行。
3. **标记与测量。** 按[接入协议](protocol.md)标记稳定 ID、分组、内容与外框。运行代码等待字体和图片，实测边界，再建立独立移动外壳。改宽度后重新换行、测高；外框不能小于内容，不缩放文字。
4. **声明关系。** JSON 只写端点、端口、线型、颜色和时序行，标签文字留在 DOM。共用代码计算端点并避让节点与注释。标签实测尺寸并寻找可用位置；拥挤时扩大通道或调整相关模块，不能按字符数猜宽度。
5. **检查。** 打开封装后的 HTML，查看完整构图及“布局提示”。定位溢出、重叠、标签遮挡、穿线、页眉侵入与越界；修正实际问题。提示不代替核对语义与阅读节奏。节点移动不会触发整图重新布局。
6. **导出。** 点击“保存 HTML”保存当前布局，再用“导出 PNG”生成完整画布。重新打开保存的 HTML 和 PNG，检查长图底部、箭头、分支、注释及资源；不能只交付当前屏幕截图。

## 直接复用

需要 HTML 自动换行时复制[最小制作起点](../assets/starter.html)，调整内容、布局、主题与关系。需要其他构图时只读取[四类示例的精简源码](examples.md)，不用读取包含压缩运行代码的成品 HTML，更不用重新生成编辑器。

在图解 Skill 目录执行（其他工作目录使用脚本的实际路径）：

```sh
python3 scripts/prepare_diagram.py artwork.html --output artwork.editable.html
```

仅要求 Python 3 标准库。封装器检查重复 ID、缺失端点、端口、状态版本及未内嵌资源，然后内联已构建的 JavaScript。封装成品不需要 npm 或构建工具。重新封装同一文件不会重复内嵌运行代码。

制作环境已有 Node.js、Playwright 与浏览器时，直接运行[浏览器检查与导出脚本](../scripts/inspect_diagram.mjs)，无需阅读运行时源码或另写检查脚本。在安装了 Playwright 的工作目录执行，下面的脚本路径按实际 Skill 位置调整：

```sh
node scripts/inspect_diagram.mjs artwork.editable.html --output checks
```

默认使用 Chromium；`--browser chrome` 或 `--browser msedge` 使用已安装的桌面浏览器，`--scale 1` 改为一倍 PNG。脚本离线加载成品，输出完整 PNG、保存重开的 HTML 与 JSON 报告，检查初始化、几何提示、导出尺寸和保存重开的一致性。有问题时退出码非零；报告保留对象 ID 和诊断详情。它不会移动模块或修正文案。制作环境没有这些依赖时，使用已有浏览器工具完成同样检查；HTML 成品和 Python 封装器的使用不受影响。

接着用实际可用的图像工具打开导出的 PNG，对照来源查看。报告中的 `passed` 只代表列出的程序检查；`notChecked` 列出仍需作者核对的语义、视觉与编辑操作。交付说明分别写明实际完成的检查和剩余项。读取 PNG 尺寸、生成截图文件或得到零几何提示，都不代表模型已经看过图像；无法查看时明确说明。

## 空间与资源

- 页眉、主体、页脚独立。`gap` 是页眉到主体的最小初始间距；工具中的“主体顶部间距”与“整体下移”同时更新节点、标签和回路。
- 未限制画幅时画布自动向右、向下增长，页脚跟随主体。固定画幅使用 `fixedSize: true`；不足时报告问题，由作者调整构图或提出扩大画布的具体取舍。
- 每个区域需要留出真实线槽。短箭头可以连接相邻模块，但带长标签的路径需要更多空间。路径受阻会给出提示，不保证任何密度下都能自动找到可读解。
- 字体使用可用系统回退或内嵌字体，图像使用 data URL。封装前内嵌 CSS、字体和图片，禁止外部脚本、资源链接及 CSS `@import`。装饰不承担精确关系，复杂装饰默认不标为可编辑节点。
- PNG 由内嵌且锁定为 1.11.13 的 [html-to-image](https://github.com/bubkoo/html-to-image) 生成，默认 2 倍，可选 1 倍；不含编辑器、不受查看缩放影响。资源失败、对象越界或超过安全尺寸时明确报错。

只在允许的浏览器环境验证。不能访问或未实际检查时说明验证缺口，不能声称成品已视觉通过。SVG/PDF 不是内置导出格式；用户明确需要时另行采用经过验证的方式。
