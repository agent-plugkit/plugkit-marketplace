# 制作方法：从起始模板到 PDF

## 起始模板

把本 Skill 的 `assets/deck.html` 复制进作品目录，改名为 `deck.html`，在它上面写，不要从空白文件开始。它已经带好三件事：

- **画布骨架**：每页一个 `<section class="slide">`，尺寸取 `--canvas-width` 和 `--canvas-height`，超出画布的部分被裁掉。
- **打印版式**：打印和导出 PDF 时，所有页按顺序竖排，每页一张纸，`@page` 的尺寸就是画布。检查脚本也在这个版式下逐页检查，所以检查过的就是导出的。
- **放映**：浏览器里一次显示一页，按窗口等比缩放居中；方向键、空格、PageUp/PageDown、Home/End 翻页，F 全屏，地址里的 `#3` 打开第 3 页。

使用时：

- 把 style.md 的 `:root` 整段粘贴进模板的第 1 段，字体链接放进 `<head>`。
- 版式写在第 3 段，只用 style.md 的变量。不要改第 2 段的骨架和放映规则；改画幅时只改 `--canvas-*` 和 `@page` 的尺寸，检查命令的 `--canvas` 跟着改。
- 页面里不要用 `vw`、`vh` 和 `position: fixed`：放映时整页被缩放，导出时没有视口，这些单位两边都会错位。尺寸一律用 px 或 style.md 的变量。
- 每页的 `aria-label` 写成「第 n 页」或这一页的标题，读屏软件只读当前页。

## 栏位与字号

- 每页用同一套网格：`.slide` 的内边距取 `margin`，内容区按 `columns` 和 `gutter` 分栏（例如 `display: grid; grid-template-columns: repeat(var(--columns), 1fr); column-gap: var(--gutter)`）。零间隙拼板这类风格不用 `column-gap`：按它的文法用网格轨道和边框排，接缝落在哪里以文法为准。各页型的区域按第 3 步定下的栏位放。
- 本场景适配要求标题跨满某几栏时，用 `muse.py fit <template> --scene slides --chars <字数> --span <栏数>` 推导。幻灯片是固定画布，直接用它打印的「参照画布 1920px」那一行的字号，不用流式表达式；标题设为不换行。竖排用 `--vertical`。
- 画幅不是 1920 × 1080 时（例如 4:3 的 1440 × 1080），正文字号保持 style.md 的值；`fit` 的字号按「可用宽度 ÷ (字数 + (字数 − 1) × 字距)」用新的画布宽度重算。
- 现场讲的文稿按会场最后一排设计：要读的内容不小于 `size-body`；`size-meta` 只给页码、来源和固定区。检查脚本会报出小于 `size-meta` 的字。

## 数据页的图表

- 只有一两个关键数字时，直接排成大字，不做图。
- 需要图表时，从数据生成图，不手抄数值：有数据文件时读文件；数字只在对话里时，把它们写成页内的一个数组，由一小段脚本生成条形和标签，不逐条手写坐标。风格声明了 `data` 场景时（`muse.py show <template>` 能看到），可以按 `data-figure` 的方法用同一个 Template 解析 `data` 场景做图，导出 SVG 放进这一页；没有声明时，用内联 SVG 或 HTML 画。颜色先按本场景适配里数据页的写法；适配没有写时，只用 `ink`、`ink-muted` 和一处 `accent`。
- 图里的字同样不小于 `size-meta`，刻度和图注比幻灯片正文小一级即可；结论写在页标题里，图里不再重复一遍长句。

## 图像与动效

- 照片和插图放在作品目录里用相对路径引用，PDF 和 PNG 会一起导出。Seed 写着「制作工具」时（例如网点模块），照 style.md 的说明复制进作品目录使用。要求单文件交付时，把工具全文内联进页面的 `<script>`（工具文件开头写了可以这样做）。给工具传尺寸时用 px 值或 `offsetWidth`，不用 `getBoundingClientRect`：放映时整页被缩放，后者量到的是缩放后的尺寸。
- 不做逐条出现之类的页内动画：PDF 和 PNG 里没有它们，检查脚本也只看最终状态。需要分步讲解时拆成几页，每页多出现一条。
- 翻页动画只按风格适配的要求加；要加时只用透明度，并尊重 `prefers-reduced-motion`。

## 导出与交付

- 检查脚本每跑一次就重新导出逐页 PNG（`deck-slides/01.png…`）和 `deck.pdf`，交付用最后一次评审导出的文件。PDF 来自打印版式，文字可以选中和搜索；`--scale 2` 导出两倍像素的 PNG。
- 没有 Playwright 时，可以在 Chrome 里打开 `deck.html`，打印 → 存储为 PDF，边距选「无」，勾选「背景图形」。这样导出的 PDF 没有经过检查，交付时写明。
- 用户要讲稿时，单独写一份 `notes.md`，按页号分段，不放进幻灯片。
- 可编辑的 .pptx、Keynote 和 Google Slides 文件不支持。需要在这些软件里使用时，只能把 PDF 或 PNG 作为整页图片放进去，文字不能再编辑；交付时如实说明。
