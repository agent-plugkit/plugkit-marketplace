# 页型原型

页型回答「这一页需要哪些区域、按什么顺序读」。先按这一页要说的话选页型，再用 style.md 的文法和本场景适配决定区域占几栏、对齐在哪、留白落在哪里。同一页型在不同风格下会长得完全不同。

## 整份的节奏

- **讲述线决定页序。** 封面之后先说清楚为什么值得听，再按段推进，最后收在要记住的那句话上。每段可以用一张章节页开头；只有三四页的短讲不需要章节页。整份只有一张章节页时，它的编号取讲述线里这一段的段号，和固定区里的章节名一致；不想编号时只写章节名。
- **疏密交替。** 要点、数据、对比是密的页；章节、引文、封面和结尾是疏的页。连续三页或更多密页时，在中间插一页疏的，让听众换口气。
- **一页一件事。** 一页要说两件事时拆成两页。要点超过风格适配允许的条数时也拆页，不缩小字号硬塞。
- **固定区。** 页码、章节名、演示的短标题放在固定区，每页同一个位置；封面、章节页和结尾页可以不放。固定区用 `size-meta`，不承载要读的内容。
- **页标题写结论。** 内容页的标题尽量写成一句断言（「夜间骑行三年翻了一倍」），而不是名词（「骑行数据」）。这样只看页标题就能复述整场。

## 封面

演示的入口，也是导出 PDF 的第一页和缩略图。

- **区域**：标题、副标题或一句导语、讲者与机构、日期与场合。
- **阅读顺序**：标题 → 副标题 → 讲者、日期与场合。
- **密度**：低。
- **关键判断**：标题是整页的焦点，按风格适配推导字号；讲者和日期聚成一组，不散在四角。

## 章节页

段与段之间的停顿，告诉听众进入了哪一段。

- **区域**：章节编号、章节名，可选一句引导。
- **阅读顺序**：编号 → 章节名 → 引导。
- **密度**：最低，页面的大半是留白或色面。
- **关键判断**：所有章节页用同一个版式，只换编号和章节名；编号和章节名的关系要比内容页的页标题更醒目。

## 要点页

用几条并列的话支持一个结论。

- **区域**：页标题（结论）、2–4 条要点、可选的补充说明、固定区。
- **阅读顺序**：页标题 → 要点按顺序 → 补充说明。
- **密度**：中。
- **关键判断**：要点之间同级、同形，每条一行（自己读的文稿可以两行）；有先后顺序时编号，没有时不编号。补充说明退到窄栏或页脚，不和要点抢层级。

## 数据页

用一个数字或一张图证明一个结论。

- **区域**：页标题（结论）、关键数字或图表、单位与对比基准、来源、固定区。
- **阅读顺序**：结论 → 数字或图 → 单位与基准 → 来源。
- **密度**：中。
- **关键判断**：只有一个数字时让数字本身成为焦点，写明单位和跟什么比；需要图表时一页一张图，强调只落在结论指向的那一项，其余退成弱色。来源用 `size-meta` 写在页面上；用户没给来源时写「来源：待补」，不猜。

## 引文页

让一句原话替你说。

- **区域**：引文、出处（人名、身份或来源）。
- **阅读顺序**：引文 → 出处。
- **密度**：低。
- **关键判断**：引文逐字来自用户或资料，不改写、不编造；超过约 60 个汉字时只引最关键的一句。出处紧跟引文，不放到页脚。

## 对比页

把两个（最多三个）对象放在一起看出差别。

- **区域**：页标题（结论）、每个对象一栏（栏名和同构的条目）、可选的一句结论。
- **阅读顺序**：页标题 → 第一栏 → 第二栏 → 结论。
- **密度**：中到高。
- **关键判断**：各栏同宽或按风格的栏位分配，条目逐行对应，同一行比的是同一件事；差异处才用强调，不给其中一栏整体上色来暗示好坏。

## 结尾页

收住整场，告诉听众接下来做什么。

- **区域**：要记住的那句话或下一步、联系方式或链接、可选的致谢。
- **阅读顺序**：那句话 → 下一步或联系方式 → 致谢。
- **密度**：低。
- **关键判断**：不用一页只写「谢谢」；那句话应当和封面、讲述线呼应。联系方式和链接是必须准确的事实，写进 `facts.txt`。
