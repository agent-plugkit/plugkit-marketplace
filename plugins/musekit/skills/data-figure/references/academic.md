# 学术出版 profile

论文、投稿、学位论文和学术海报里的结果图在通用流程之外，再守住下面的规范。期刊或学校给了制图要求时，以它为准。这些规范优先于 style.md 和它的本场景适配；风格仍然决定颜色、字体、细线和对齐。

## 科学表达的边界

- 不从视觉参考中抽取实验结果、统计结论、数据点或科学机制。不为画面完整补造显著性星号、误差条或趋势。
- 统计量要有含义。能从原始数据计算时，说明计算方式；只有均值时不伪造离散程度。SD、SE 和置信区间不互换，图注写明用的是哪一种。
- 没有实验设计信息时，不自动选择显著性检验。样本 SD 用 `ddof=1`；是否画它，由图要表达的变异决定。
- 标明单位、变换、截断与缺失值处理。坐标范围、基线、对数变换和归一化要能解释；截断坐标或展示相对值时，让读者看得见。
- 示例数据和概念示意明确标识。数据不足时不能用插值或生图补成「测量结果」。
- 随机抖动只用来分开重叠的点时，固定随机种子，并说明它只改变横向显示位置，不改变观测值。

## 版面

- 图内不放图题。结论句写成论文图注的第一句，副标题里的范围和样本量也写进图注。
- 面板按期刊惯例编号 a、b、c，风格的编号装置（细线、位置）可以保留。
- 背景用白色或透明，不用 style.md 的 `paper`；印在白纸上会多出一块色底。
- 「示例数据」声明在图内脚注和论文图注里各写一句。

## 尺寸与字号

- 目标宽度以期刊的栏宽为准，常见单栏约 85–90 mm，双栏约 170–180 mm。先按这个宽度排版，再导出；高分辨率 PNG 不能替代按实际宽度检查字号。
- 字号按期刊要求，没有要求时导出后实际大小在 6–9 pt 之间，面板编号可以略大。style.md 的字号阶梯只用来定相对层级。
- 线宽导出后不细于 0.5 pt。
- 字体用 style.md 的 `font-text`，中文用 `font-cjk`（本场景适配允许时，刻度可以用 `font-mono`），或期刊指定的字体；希腊字母、上下标和数学符号在导出文件里逐个检查。

## 格式

- 线条图和散点图交矢量格式（PDF 或 SVG）；照片类内容或像素很多的热图交位图，通常 300 dpi 以上（以期刊要求为准）。
- 矢量文件检查字体是否嵌入、裁切和标签有没有越界。

## 评审附加项

- 逐个核对数据点、汇总量、统计口径和单位，图注里的 `n` 与数据一致。图上和图注的数值用同一舍入规则，写进交付说明；末位落在 5 上时用十进制计算（例如 Python 的 `decimal`），避免浮点误差让复核对不上。
- 按栏宽打印或按实际尺寸查看，最小的字读得出。
- 图注能单独读懂：变量、单位、统计量、样本量、数据来源。
- 交付数据、代码，以及按「格式」一节导出并打开检查过的实际文件；没有打开过导出文件，不声称通过出版检查。
