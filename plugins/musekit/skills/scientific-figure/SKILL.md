# Scientific Figure

先明确图要支持什么科学问题，再决定怎样呈现证据。默认交付实际图形与可复用源文件；用户只要制图方案时按其范围工作。

## 问题 → 证据 → 编码 → 制作 → 核对

1. **明确问题和资料。** 阅读提供的数据、论文段落、实验说明或过程资料，确定比较、趋势、分布、关联或机制解释中的主问题。确认变量、单位、样本、已有统计量和目标尺寸；阻塞解读的缺口需要补充。
2. **区分数据图与示意图。** 数据图呈现给定观测，科学示意图解释已有过程与关系；两者可以组合成分面，但要让读者分清哪些是测量、哪些是概念表达。
3. **选择表达与方向。** 先选择能回答问题的图形编码和分面，再采用用户规范、参考或 seed 的字体层级、色彩职责和标注方法。按[seed 简报](../../references/seed-brief.md)适配；网站或海报 seed 不提供科学制图规范，也不证明科学结论。
4. **制作。** 数据图优先使用当前环境可用的标准绘图工具，保留数据与绘图代码；示意图可以使用自定义 SVG 或其他可编辑工具。生成插画可以辅助概念表达，数据点、公式、方向与科学标注保持可验证。
5. **按出版尺寸查看。** 核对原始资料与实际图中的数值、单位、轴、图例、标注、面板关系和不确定性说明，再检查字号、线宽、对比与阅读顺序。

图形选择与制作细节见[场景方法](references/methods.md)，包含完整小数据集的过程见[制作示例](references/examples.md)。

## 科学表达的边界

- 不从视觉参考中抽取实验结果、统计结论、数据点或科学机制。不能为了画面完整而补造显著性星号、误差条或趋势。
- 统计量需有含义。能从提供的原始数据计算时说明计算方式；只有均值时不伪造离散程度。不能把 SD、SE 和置信区间互换。
- 标明单位、变换、截断与缺失值处理；刻度与比例服务分析，不能制造没有数据支持的差异或因果关系。
- 颜色可借鉴，编码必须重新建立。增加标记、线型、直接标签或其他颜色以满足区分需求，不受参考的双色印刷限制。
- 示例数据和概念示意明确标识。不可确认的机制关系不能借绘图变成已证实事实。

## 交付

交付实际图形、绘图代码或可编辑源文件，以及解释变量、单位和统计表达的短图注。按用户要求提供 SVG/PDF 或指定分辨率的位图，核对导出后的实际文件。没有查看实际成品时不声称通过出版检查。
